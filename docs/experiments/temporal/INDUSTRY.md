# Open implementations and practical research

| Source | Available method | Relevance and decision |
|---|---|---|
| [Borghesi et al., Expert Systems with Applications2023](https://doi.org/10.1016/j.eswa.2023.119780), Politecnico di Torino/Math&Sport | Temporal convolutional possession/game-state models, with permutation-invariant trajectory aggregation; paper data confidential | Direct H/A/D task match. We built an original two-head residual TCN on our tracking-derived geometric features; this is an adaptation of temporal modelling, not a reproduction of the paper's private-data results. Its published accuracy is not comparable with our official spellF1. |
| [Official PathCRF, KDD2026](https://github.com/hyunsungkim-ds/pathcrf), [paper](https://arxiv.org/abs/2602.12080) | Public MPL2.0 code and pretrained checkpoints; set/temporal attention plus dynamic masked CRF infers player-to-player possession paths without ball tracking | Pinned checkpoint140 loaded with weights-only deserialization and passed a synthetic inference/CRF smoke test. It is not part of v4. The published setup uses in-play windows and finite trajectories; source DFL overlap, missing detections and fragmented identity require a separate adapter and external quality benchmark. Smoke success is not a football accuracy result. |
| [Tryolabs soccer-video-analytics](https://github.com/tryolabs/soccer-video-analytics) | MIT video detection/tracking and possession demo | Runnable reference for perception. Its README explicitly says the released ball detector overfits a few videos. We therefore do not treat its downloadable checkpoint as a production-quality possession solution. |

These are inspectable implementations/research, not evidence that every commercial supplier uses these exact models. A replacement still needs match-isolated testing on the actual H/A/D objective, observed/missing-data handling, source-shift checks and exact artifact reproduction. V4 uses our trained temporal model and frozen external-trained boosting components; it does not copy third-party model quality claims.
